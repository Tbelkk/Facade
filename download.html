Download Facade for Windows

Install the Facade app and open any old desktop program. Facade gives it a modern look and an AI assistant, without changing the original.

Download for Windows
Facade-Setup.exe · Windows 10 & 11 · 64-bit

Install

  1. Run Facade-Setup.exeFollow the installer prompts.
  2. Start Facade as administratorNeeded so Facade can read apps that run with admin rights.
  3. Open any old appFacade modernizes it automatically. Toggle it off anytime.

Requirements

  • Windows 10 or 11, 64-bit
  • Internet connectionUsed for NVIDIA Nemotron.
  • Administrator access

Facade is Windows only. It works through the Windows accessibility layer, so Mac and Linux aren't supported.
