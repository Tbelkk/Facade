What Facade does

Facade makes old software easy to use, without replacing it.

Hospitals, offices and governments still run on desktop software from the '90s and 2000s. It's too important to replace and too painful to use. Facade sits on top of that software and gives it a clean, modern look, plus an AI assistant that does tasks for you in plain English.

How it works
  1. Open your old app.Facade reads the screen the same way a screen reader does. No code changes, no API needed.
  2. It gets a modern look.NVIDIA Nemotron understands each screen and redraws it in a modern version of the app's own style.
  3. Ask it to do the work.Type something like "text everyone with an appointment tomorrow" and Facade clicks through the app for you.
Why it's safe
  • The original app is never changed. Switch Facade off anytime.
  • Every value you see comes from the real app, not the AI.
  • Anything risky waits for your approval, and every action is logged.
