What Facade is

DLSS for software.

DLSS doesn't turn every game into the same game. It takes that game's art and renders it better. Facade does the same for software: same app, same identity, same data, rendered for this decade.

Too critical to replace

Legacy systems run front desks, clinics, warehouses and government. Replacements take years and often fail.

Too painful to use

Cryptic errors, dense gray screens, and workflows that take a dozen clicks across five windows.

No API, ever

Most legacy software has no API. The screen is the only way in, so that's where Facade works.

How it works

One pipeline. Any app. Nothing prebuilt.

  1. DetectWindow opens or screen changes
  2. CaptureAccessibility tree + screenshot
  3. FingerprintSeen this screen before? Use the cache
  4. UnderstandNemotron Nano Omni labels every control
  5. StylePalette, traits and density, once per app
  6. RenderOverlay draws the modern UI in the app's style
  7. BindLive values ↔ real controls, no AI in the loop
  8. ActAgent tasks run through the same controls
Slow path · seconds

Once per new screen

Nemotron labels the screen. The result is cached by fingerprint, so the second visit is instant.

Fast path · milliseconds

Continuous

Values stream from real controls and actions go back through accessibility patterns. No AI here, so it never invents data.

Data never comes from the model

Every write is read back. A mismatch stops the agent and reports it.
