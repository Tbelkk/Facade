# Format examples (one of each)

These show the **shape** of the data passed between RESTore's components (see Section 7 of FACADE-PLAN-v4.md).
They are examples to code against, not product data: the Explorer's real output replaces them.

- `site_map.example.json`: Explorer → Console, Operator
- `data_model.example.json`: Explorer → Operator, backend, Console
- `operations.example.json`: Explorer → Operator, API/MCP
